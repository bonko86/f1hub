# Lagikoner

Vita laglogotyper hämtade från Formula 1:s offentliga lagsida 2026-10-25:
https://www.formula1.com/en/teams

Originaladress: `https://media.formula1.com/image/upload/c_lfill,w_48/q_auto/v1740000001/common/f1/2026/{slug}/2026{slug}logowhite.webp`.

Jolpica-ID till slug: `red_bull` → `redbullracing`, `rb` → `racingbulls`, `haas` → `haasf1team`, `aston_martin` → `astonmartin`. Övriga filnamn använder samma slug som Jolpica-ID.

Logotyperna tillhör respektive lag. Nya eller okända lag visas med namn utan en påhittad ikon. Vid förarbyte under säsongen visas ikoner för de konstruktörer som Jolpica anger i mästerskapstabellen.
