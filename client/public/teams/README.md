# Lagikoner

Aston Martin visas från användarens `astn martin.png`, sparad som `aston-martin-source.png`. SVG-visningsytan beskär transparenta marginaler till logotypens pixelgränser (394, 516, 809 × 202) utan att ändra originalbilden.

Laglogotyper i färg hämtade från Formula 1:s offentliga lagsida 2026-10-25:
https://www.formula1.com/en/teams

Originaladress: `https://media.formula1.com/image/upload/c_lfill,w_96/q_auto/v1740000001/common/f1/2026/{slug}/2026{slug}logo.webp`.

Mercedes, Audi, Aston Martin, Cadillac, Racing Bulls, Williams och Haas använder den transparenta monokroma varianten `2026{slug}logowhite.webp` för att synas på mörk bakgrund utan en vit ruta.

Jolpica-ID till slug: `red_bull` → `redbullracing`, `rb` → `racingbulls`, `haas` → `haasf1team`, `aston_martin` → `astonmartin`. Övriga filnamn använder samma slug som Jolpica-ID.

Logotyperna tillhör respektive lag. Okända lag visas utan en påhittad ikon. Vid förarbyte under säsongen används endast konstruktören i förarens senaste publicerade loppresultat.
